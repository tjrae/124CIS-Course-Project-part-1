# Tyler Jacob Raeside — Technology Portfolio

A four-page HTML5 student portfolio for CIS 124 Web Development I.

## Pages

- `index.html` — Home and personal introduction
- `resume.html` — Education, work history, skills, and activities
- `projects.html` — Technology coursework and accomplishments
- `contact.html` — Contact information (no message form)
- `styles.css` — Shared stylesheet used by all four pages

Open `index.html` in a web browser. All four HTML documents link to the same `styles.css` and navigate between each other.

The site uses the student's supplied information and adds short Lorem ipsum starter paragraphs as requested. To formally confirm no errors or warnings, upload each HTML document to https://validator.w3.org/ and review the report.
